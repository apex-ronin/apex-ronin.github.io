Before we talk

A few practical answers.

Can I inspect the work before getting in touch?

Yes. Start with Primordial Galaxy and the research repositories. The GovTech Hunter page explains the architecture and links to the implementation.

Are services sold as fixed packages?

There are no published fixed-price packages on this site. Scope, availability, and commercial terms are agreed directly for each engagement.

Does this site run a live GovTech Hunter demo?

No. It presents the documented architecture and links to the public repository. It does not connect to private project data or a running pipeline.

Does generating a brief submit my information?

No. The brief is created locally in your browser. Copy or download it, then use the published GitHub route to make contact.
