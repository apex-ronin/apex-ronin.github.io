01 / Authority model

Four layers. Ranked, not blended.

Most systems flatten evidence and inference into one output. Here they are structurally separate, and each layer can only read downward.

L1
Validated source

Acquisition

Retrieval from a named, versioned source. Content hashed and snapshotted at read time. A source that cannot be re-fetched or cited does not enter L1.

L2
Recorded state

Deterministic comparison

Fixed procedures diff snapshots, resolve entities against stable keys, and emit typed assertions. Same inputs, same state — every time.

L3
Orchestration

Workflow and coordination

Durable execution across agents and tools. Retries, checkpoints, and handoffs are state, not vibes. A crash resumes from the last committed step.

L4
Interpretation

Model reasoning

Models read L1–L3 and produce judgement — ranked, argued, and always marked as interpretation. Promotion upward into action requires governance sign-off.

02 / Systems

Nine systems, expandable. None of them a monolith.

Each is a bounded component with a stated contract. They compose; they do not merge.

03 / Why deterministic first

Models are the worst place to store a fact.

A model asked the same question twice may answer differently. That is a feature for judgement and a defect for custody.

The practical consequence: you can re-run a six-month-old analysis and get the same L1–L3 record, then compare how two different models interpret it.

Non-goals

  • Not an autonomous decision-maker
  • Not a replacement for statutory process
  • Not a chat interface over PDFs
  • Not deployed at scale — reference implementation stage
